01 · 核心正文

先看清四层结构

一个稳定的 AI 开发环境由下而上分成四层：操作系统与终端、包管理器、语言运行时、AI/机器学习库。上层依赖下层，所以排错也应自下而上：先确认系统命令可用，再检查 Python 版本和虚拟环境，最后检查 PyTorch、NumPy 等库。

环境问题最常见的根源不是代码本身，而是版本不一致或依赖装到了错误的位置。把每个项目放进独立虚拟环境，并记录依赖版本，能显著减少“在我的电脑上可以运行”的问题。

02 · 核心正文

建立最小可用环境

初学阶段不必一次安装所有工具。先准备 Git、Python 3.11 以上版本、一个代码编辑器和包管理器。创建虚拟环境后，只安装当前练习需要的 NumPy 与 Jupyter。以后进入大模型、智能体或 Web 应用课程时，再按需加入 Node.js、Docker 与 GPU 工具链。

验证环境时要运行一个真实但很小的任务，例如创建向量并计算点积。只看版本号不够，因为库可能安装成功却无法正常导入或执行。

专业术语

本课术语表

运行时（runtime）

执行某种语言程序所需的环境，例如 Python 3.12。

包管理器（package manager）

安装、锁定并更新项目依赖的工具。

虚拟环境（virtual environment）

让不同项目使用互不干扰的依赖版本。

可复现构建

其他人按相同配置可以得到一致的运行结果。

动手练习

环境健康检查

  1. 记录操作系统、终端、Git 与 Python 的版本。
  2. 创建名为 .venv 的虚拟环境并激活它。
  3. 安装 NumPy，计算向量 [1, 2, 3] 与自身的点积。
  4. 把命令、版本与运行结果写进 README，形成可复现记录。
